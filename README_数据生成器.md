# 肌电模拟数据生成器 使用说明

## 功能
生成模拟表面肌电（sEMG）数据（.txt），供 EMG-Analyzer 软件分析。

三个按钮：
1. **生成正常咬合数据**（健康对照）——软件指标全部落在参考范围内（绿色）
2. **生成 TMD 紊乱咬合数据**（右侧为患侧）——不对称指数显著超标（红色），作异常对照
3. **鲁棒性扫描**——对正常数据批量注入扰动，输出指标退化曲线（SVG）+ 失效阈值（CSV）

## v4 版本新增（鲁棒性验证体系）
- **扰动注入**（4 类，均为单侧/右侧注入以考察对称性判定边界）：
  - 单侧加性噪声（σ 0→40）：模拟电极接触不良
  - 单侧削顶饱和（幅值上限 160→21）：模拟放大器饱和
  - 单侧电极串扰（比例 0→0.8）：模拟电极位移/耦合
  - 通道增益不一致（比例 0→0.8）：模拟放大器增益差异
- **退化曲线**：固定种子扫描 10 个强度点，记录 4 项指标的平均绝对值 → SVG 曲线图（可直接插入 Word，浏览器可打开）
- **失效阈值**：任一指标平均绝对值首次越出临床参考带（|As|>20% 或 |Ac/Tc|>10%）对应的扰动强度
- 典型结果（正常基准，seed=42）：加性噪声在 σ=22 时 Tc 首先失效、σ=30 时 As-MM 失效；增益不一致 0.30 时 Tc 失效、0.52 时 As 失效；串扰 0.52 时 Tc 失效；Ac 对三类扰动全程鲁棒

## v3 版本新增（平台化升级）
- **指标插件化**：`register_metric(名称, 计算函数, 参考范围, 上限)` 可注册自定义指标，评估/自检自动纳入
- **生理特征定量核对**：生成完成对话框输出「指标 + 生理特征」双层核对，把内置生理特征升级为可验证特征：
  - 静息患/健 RMS 比（静息张力）
  - 早启动提前量（患侧相对健侧起跳时间，ms）
  - 持续咬合患/健幅值比（RMS 口径）
  - 疲劳递减率（患侧 vs 健侧）

## v2 版本改进（对齐软件指标算法）
软件按咬合区间内各通道 RMS 计算指标，v2 通过「区间 RMS 闭环校准」确保指标可控：

| 指标 | 参考范围 | 正常模式实测 | TMD 模式实测 |
|------|---------|-------------|-------------|
| As-MM 咬肌不对称 | ±20% | ≈ +1%（绿） | ≈ -26%（红） |
| As-TA 颞肌不对称 | ±20% | ≈ -1%（绿） | ≈ -23%（红） |
| Ac 活动指数 | ±10% | ≈ -6%（绿） | ≈ -4%（绿） |
| Tc 转矩指数 | ±10% | ≈ 0%（绿） | ≈ -25%（红） |

主要改动：
- 时间结构改为模板式：静息 → 3 次均匀咬合（各约 2.2s）→ 收尾静息（旧版前段轻咬太弱，软件咬合检测不到）
- 幅值量级对齐模板：咬合区间 RMS 20~35、波形峰值 ±100~200（旧版 RMS 仅 5~13）
- 每个咬合区间按目标 RMS 闭环校准，双侧对称性精确可控
- 去除正常模式的单侧大漂移（旧版左颞肌 -140 漂移是 As-TA 超标的元凶），漂移全部改为双极性对称
- TMD 保留全部异常特征：患侧静息张力高、早启动 100~200ms、节律不规则、震颤、后段疲劳+漂移+间断肌电静默
- 生成完成对话框会显示本次数据的指标自检结果

## 运行方式

### 方式一：直接运行 exe（推荐，无需 Python 环境）
双击 `肌电数据生成器.exe`，点对应按钮即可生成数据。

> exe 已内置 numpy 与 tkinter，可在任意 Windows 电脑上直接运行，无需安装 Python。

### 方式二：Python 源码运行（需 Python 环境）
```bash
python EMG_Data_Generator.py          # 打开图形界面
python EMG_Data_Generator.py normal   # 命令行生成正常咬合数据
python EMG_Data_Generator.py tmd      # 命令行生成 TMD 数据
python EMG_Data_Generator.py normal 42  # 指定随机种子（可复现）
python EMG_Data_Generator.py scan 42 "D:\输出目录"   # 鲁棒性扫描
python EMG_Data_Generator.py report 100 1 "D:\输出目录"  # 多种子统计报告（Results 真实数据）
```
> 需要安装依赖：`pip install numpy`（GUI 还需要 tkinter）。

## v5 新增：多种子统计报告（`report` 命令）
针对论文 Results 章节「必须用真实跑出的多种子数据」的要求，一键产出两类 CSV：

**1. 指标误差汇总**（`指标误差汇总_<n>种子.csv`）
- 两种模式 × 4 项指标，各跑 n 个随机种子（默认 100）
- 给出每个指标的 均值、标准差、最小值、最大值、越界样本数、越界率
- 100 种子实测：正常模式 4 项越界率全 0%；TMD 模式 As-MM/Tc 越界率 100%、As-TA 99%（Ac 在范围内），误差区间可直接写进 Results

**2. 退化曲线数值**（`退化曲线_<扰动>_<n>种子均值.csv`）
- 4 类扰动 × 10 个强度点，每个点取 n 种子平均后的 4 项指标值
- 数值对应 v4 的退化曲线图，是图背后的真实数据表

用法：`python EMG_Data_Generator.py report [种子数] [起始种子] [输出目录]`

## 数据规格
- 6 列、10000 行、500 Hz 采样（共 20 秒）
- 列顺序（严格按模板）：`LMM, Channel 2, Channel 3, LTA, RMM, RTA`
  - LMM 左咬肌、LTA 左颞肌、RMM 右咬肌、RTA 右颞肌
  - Channel 2 / Channel 3 为基线列（直流偏置 ≈ 0.5 / 2.0，量级与模板一致）
- 三段结构：前段(0~10s 静息+间断轻咬合)、中段(10~15s 持续中等咬合)、后段(15~20s 伪迹/疲劳)

## 两种模式的关键差异

| 特征 | 正常咬合 | TMD 紊乱咬合 |
|------|----------|--------------|
| 双侧对称性 | 对称，幅值差≤20% | 患侧(右)明显高于健侧 |
| 患/健幅值比 | ≈1.0 | 1.5~1.8（RMS） |
| 患侧静息张力 | 正常 | 显著增高 |
| 激活时序 | 双侧同步 | 患侧早启动 100~200ms |
| 患侧波形 | 规则尖峰 | 叠加细微震颤样高频 |
| 后段疲劳 | 轻度 | 患侧幅值递减 + 间断肌电静默 |
| 左颞肌漂移 | 后段漂移最显著(≈-140) | 患侧右颞肌漂移最显著 |

## 输出
生成的 txt 保存在脚本同目录，命名格式：`<模式>_<时间戳>.txt`。

## 提示
- 「随机种子」留空则每次结果不同；填入数字可复现同一份数据。
- 可在源码顶部修改 `N_ROWS`、`FS`、三段边界 `SEG1_END`/`SEG2_END` 等全局参数。
